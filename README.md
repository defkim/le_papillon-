# le_papillon-

## Description du jeux
Le papillon est un jeu à but éducatif qui propose, à travers plusieurs mini-jeux, de comprendre le cycle de vie d'un papillon. 

### Mini-jeux
- mini-jeu 1 : Le joueur incarne une chenille qui doit sauter sur des plateformes, afin de récolter un nombre de feuilles données, en utilisant les flèches du clavier.
- mini jeu: 2 : Le joueur utilise la barre d'espace et clique dessus afin d'être dans la partie verte d'une jauge donnée. Cela a pour effet de stabiliser la chrysalide, pendue à un arbre qui bouge à la manière d'un pendule.
- mini-jeu 3 : Le joueur utilise la souris afin de cliquer sur/éliminerles ennemis qui tente d'atteindre la chrysalide.
- mini-jeu 4 : Le joueur incarne un papillon et utilise les flèches du clavier afin de se déplacer dans un monde à défilement vertical. Le but et de poliniser un nombre de fleurs données, en les attrapants. 

### Commandes
- flèches (haut, droite, gauche) : déplacements latéraux et sauts
- espace : passer les scènes non-jouables

## Procédure de lancement 

Pour jouer, il suffit d'aller sur la page defkim.itch.io et de lancer le jeu sur la navigateur web, puis d'appuyer sur la barre d'espace pour commencer à jouer.
