# le_papillon-

Le papillon est un jeu à but éducatif qui propose, à travers plusieurs mini-jeux, de comprendre le cycle de vie d'un papillon. 

Pour jouer, il suffit d'aller sur la page defkim.itch.io et de lancer le jeu sur la navigateur web. 

Claude a été utilisé pour la relectur de bug et notamment pour les parties de code qui nécessitaient plus de savoir mathématique, notamment pour le pendule dans le niveau de la chrysalide. 

Ce projet a été développé dans le cadre du cours de jeu vidéo 2D dispensé par Loïc Cattani (Lettres, UNIL)
